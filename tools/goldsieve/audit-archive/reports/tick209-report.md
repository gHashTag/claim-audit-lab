### (1) что исправлено в инструменте

В `sieve_external_target` устранён новый класс риска целостности внешней цели: сито теперь требует запись с ключами `value`, `uncertainty` и `source`, проверяет наличие URL с протоколом `http` или `https`, конечность числовых значения и погрешности и положительность погрешности. Нечисловая, нефинитная, неполная или безадресная цель получает ситовой статус `VOID`, а не может случайно пройти как согласие. Причина дефекта была воспроизведена: при `NaN` прежняя ветвь могла получить нулевое худшее отклонение.

Самопроверка добавила две отрицательные фикстуры и одну мутационную цель удаления проверки конечности: чувствительность составила 2/2 и 1/1, решение мутанта изменилось с `PASS` на `VOID`. Новых claims, новых простых `ПОДТВЕРЖДЕНО` и новых научных вердиктов не выпускалось. В машинном baseline после изменения: 237 пройдено, 0 провалено; 45/45 положительных, 28/28 отрицательных и 17/17 мутаций.

П1 закрыт реальным GitHub Actions run 32620655152: шесть ожидаемых сочетаний macOS/Windows/Ubuntu с CPython 3.12/3.13 завершились успешно; этот самотест не подменяет каскад корпуса. Учёт BBLM согласован из одного источника: закрыто кодом 4 элемента, один остаётся машинным вопросом, расхождение источников равно 0.

### (3) что осталось недоказанным

Для `coefficient_rederivation` по-прежнему отсутствует независимый источник аналитических выражений; машинный код `analytic_source_absent` оставляет вопрос о выводе коэффициентов 0,230158 и 1,4720 открытым. Перенос напечатанных чисел не выполнялся.

Успех шести заданий GitHub подтверждает только инструментальный selftest ответа API. Полный каскад корпуса на macOS и Windows этим не доказан. На указанных версиях CPython локальный гейт прошёл на CPython 3.14.3 и 3.14.4; полный каскад на CPython 3.12.13 объявленно пропущен из-за отсутствия numpy/pyyaml, тогда как независимые от них проверки прошли. Формулировка статуса — «проверено на указанных версиях CPython», не платформонезависимость. Очередь `cross_platform_replay` и `pending/os-matrix.yaml` сохраняют область полного каскада как `platform-unverified`/`not-evaluated`.

Сводная область остаётся `STANDARD_RANGES=20412, ACTUAL_RANGES=123201`. Закон GUE для всего корпуса, независимый вывод BBLM и межплатформенная воспроизводимость полного корпуса этим тиком не доказаны.
