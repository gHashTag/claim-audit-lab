П1 выполнен через размещённый GitHub Actions run `32613321936`: сохранённый ответ API содержит шесть ожидаемых сочетаний ОС и CPython, все завершены успешно. П3: ревизия молчащих маршрутов зафиксирована; в `ci_gate.sh` для новой защиты есть отдельный самотест с отрицательными и мутационными фикстурами.
