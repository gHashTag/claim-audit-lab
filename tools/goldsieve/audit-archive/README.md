# Архив непрерывного аудита «золотое сито» (тики 1–456)

Непрерывный цикл остановлен по указанию владельца 2026-09-09. Здесь сохранены
итоги: ведомость, доклады тиков, машинные результаты кейсов и измерения об
инструменте.

## Состав

- `audit-ledger.md` — ведомость всех тиков.
- `tick-counters.json` — технические счётчики (запущено / завершено / срывы).
- `reports/` — 101 доклад тиков, каждый ровно из четырёх разделов.
- `cases/` — 33 машинных результата кейсов; опись в `cases-index.md`.
- `guard-efficacy-430.json` — содержательность 40 сторожей: 40 устанавливает,
  0 пустых, 0 без статусов.
- `science-idle-430.json` — измерение научного холостого хода (38 из 40
  коммитов трогали сторожей, 0 — кейсы сита).
- `gate-timings.tsv`, `gate-cost-402.json` — стоимость гейта по шагам.

## Что честно установлено об инструменте

1. **Каскад работает и измерен.** Гейт устойчиво даёт 150 успешных шагов, 2
   штатных пропуска (CPython 3.12 без numpy и pyyaml), 0 провалов.
   Чувствительность 1,0000 (45/45), специфичность 1,0000 (28/28), мутантов
   17/17, самопроверка каскада 256/0. Проверено на CPython 3.14.3 и 3.12 в
   одной песочнице; платформенная универсальность НЕ заявляется (ОС-матрица
   0/6, `platform-unverified`).
2. **Формальные критерии прогресса обходимы — трижды подряд.** Тик 302: подпись
   сути не ловила повтор цели. Тик 402: 13 сторожей печатали только
   `not-evaluated`, то есть не устанавливали ничего. Тик 430: критерий «сторож
   обязан предъявить `verified-in-scope`» удовлетворялся статусом о том, что
   файл прочитан, при научном статусе `not-evaluated`.
3. **Сторож не закрывает научный долг по своей природе.** Он проверяет
   контракты; вердикт об утверждении даёт кейс сита. Машинная форма правила —
   `progress_guard.py --science <клон>`.
4. **Смена цели с сторожей на кейсы себя не оправдала количественно.** Тики
   431–456 дали 26 кейсовых коммитов; **все 33 сохранённых машинных итога —
   `ВОПРОС`**, ни одного `ОПРОВЕРГНУТО` и ни одного `ПОДТВЕРЖДЕНО`. Долг стал
   подробно описан, но не закрыт. `ВОПРОС` находкой не является.

## Что осталось недоказанным

Однозначность рецепта развёртки zeta (14 вариантов, 11 воспроизводят `0,4009`,
два семейства: 7 вариантов ведущего члена и 4 варианта theta); общий `M_eff`
(33 записи С20 в 12 архивах, 26 различных значений от `545,56` до `86989,82`);
предпосылка независимости 123 201 формулы (`tests_independent=unknown`); BBLM
`analytic_source_absent` (7 из 8 элементов); 7 групп повторов внешних целей
(15 кейсов); 6 нечитаемых AST-целей; значимость расхождения zeta/GUE в сигмах
(неопределённости входа не предъявлены); внутренние несогласования корпуса
(`global std 0,429` против таблицы `0,4009`; эталон p95 `1,7518` против
`1,757099`; χ²/dof 6 строк сводки против 10 строк CSV; `Confirmed to ~2%` при
`status: OPEN`).
