## 2. Что реализовано

### С10 — неопределённость измерения (`goldsieve/stats.py`)

Терпимость больше не назначается: масштабом служит полуширина процентильного
бутстрэп-интервала с поправкой Шидака на число сравниваемых статистик
(std, p50, p90, p95, p99 скоррелированы, поэтому без поправки порог занижен).
Отклонение отдаётся в единицах `z = (наблюдение − эталон)/полуширина`.

Опора: состоятельность бутстрэпа для выборочных квантилей при непрерывной
плотности в точке квантиля (Bickel–Freedman 1981; Falk–Reiss 1989). Как
независимая перекрёстная проверка ширины реализовано неравенство
Дворецкого–Кифера–Вольфовица с постоянной Массара (1990):
\[ \sup_x |F_n(x) - F(x)| \le \sqrt{\ln(2/\alpha)/(2n)} \quad\text{с вероятностью } 1-\alpha, \]
верное для любого непрерывного распределения и любого n, без асимптотики.
Полоса проверена эмпирически: нарушена в 8 из 200 выборок при номинальных 5%,
а урезанная в четыре раза полоса — в 200 из 200 (то есть проверка не вырождена).

Результат по дзете: дефицит **std −5.50% при полуширине 0.62%, z = −9.4**;
p90 z = −4.4; p95 z = −4.5; p99 z = −3.5; p50 z = +0.6. То есть дефицит хвостов
и дисперсии — не выборочный шум, а p50 согласуется с GUE.

Результат по Хинчину: по-корзинная оценка **+1.46% при полуширине 1.82%,
z = +0.8** — то есть заявленный «систематический дефицит» на этой выборке
неотличим от шума. Прежний вывод «расхождение есть» не подтверждён.

### С11 — «слишком хорошо»

Если измерение садится на теорию точнее выборочного шума сразу по нескольким
статистикам, число, вероятнее, списано из теории. Считается верхняя граница
вероятности такого согласия при независимости статистик; в отчёте прямо
указано, что настоящие статистики скоррелированы и истинная вероятность
**больше** — это ограничение, а не оценка. Идея взята из спора Фишера о данных
Менделя (χ² «слишком мал») и из terminal digit analysis.

### С12 — независимый метод, с выводимой погрешностью

Точный закон GUE считался детерминантом Фредгольма методом Нюстрёма. Добавлен
второй путь: `refs/gue_montecarlo.py` диагонализует матрицы ансамбля GUE и
меряет расстояния напрямую. Развёртка сделана **без** полукругового закона —
делением на среднее по короткому окну, чтобы Монте-Карло не наследовал ни одной
константы из точного расчёта.

Первая версия этого файла делила на полукруговую плотность и промахнулась на
−25% по всем статистикам (нормировка ансамбля не совпадала с радиусом 2).
Ошибку поймала самопроверка файла, а не рассуждение — это ровно тот эффект,
ради которого модули обязаны иметь свою самопроверку.

Порог для С12 тоже выводится, а не назначается: берётся разброс по трём сидам
Монте-Карло (3·SEM ≈ 2.30%). Сходимость: std +0.42%, p50 −0.46%, p90 +0.17%,
p95 +0.27%, p99 −0.29% — два независимых метода дают один закон.

### С13 — объявленные пропуски

Каждый `skip` обязан быть объявлен в `skip_reasons` с точным номером сита.
Общая отписка «С» не проходит: ключ сверяется с номером сита буквально.
Незаявленный пропуск даёт вердикт ВОПРОС.

### С14 — сквозная подставка

Наблюдение подменяется заведомо неверным ответом, и **весь каскад** прогоняется
заново. Если подделка получает ПОДТВЕРЖДЕНО, конвейер объявляется вырожденным
(ПУСТО). Это отличается от С4, который лишь мерил расстояние между подставкой и
эталоном.

### С4 — набор подставок и различение двух причин

Подставок теперь может быть несколько (из мутационного тестирования: один
вручную придуманный контрпример проверяет меньше набора). Различены два случая,
раньше слитые в один статус: «подставка неотличима от эталона при этой
терпимости» (плоха подставка) и «подставка отличается, но проходит» (вырождена
проверка).

### Эталон Хинчина: аналитический хвост

\[ \ln K = \frac{1}{\ln 2}\sum_{n\ge 1}\ln n\,\ln\!\Big(1+\frac{1}{n(n+2)}\Big) \]
Слагаемые ведут себя как \(\ln n/n^2\), поэтому прямая сумма сходится как
\(O(\ln N/N)\) — отсюда и был разброс 6.09e-03. Добавлены хвостовые интегралы
для \(n^{-2}, n^{-3}, n^{-4}\) (Эйлер–Маклорен, ведущие члены). Достигнутая
устойчивость: разброс между N = 2.5·10⁵ и N = 10⁶ равен **2.7e-10** вместо
5.6e-05 без хвоста (в 2·10⁵ раз лучше), при требуемых для задачи 5e-4.
Второй путь (квадратура по мере Гаусса–Кузьмина) согласуется на 3.6e-08; в коде
честно указано, что второй путь алгебраически связан с первым и потому проверяет
реализацию, а не теорию.

В каждый отчёт входят: sha256 входных файлов, коммит корпуса, версии Python /

`goldsieve power <case>` вносит сдвиг эталона по сетке и печатает минимально

## 3. Наука: что говорит литература (полностью — `science-zeta.md`)

- Точный закон расстояний GUE: \(E_2(s)=\det(I-K_s)\) с синус-ядром (Гаудин–Мехта),
  связан с уравнением Пенлеве V ([Jimbo–Miwa–Môri–Sato 1980](https://doi.org/10.1016/0167-2789(80)90006-8)).
  Опубликованная точная дисперсия расстояния 0.17999 ([arXiv:2504.20134](https://arxiv.org/pdf/2504.20134))
  даёт std = 0.42425 — наш вычисленный детерминант дал **0.424258**, то есть
  наш эталон совпал с независимо опубликованным значением, оставаясь при этом
  вычисленным, а не процитированным.
- Surmise Вигнера отличается от точного закона порядка 1% по дисперсии и
  сильнее в хвосте \(s\gtrsim 2\); единого опубликованного числа «максимум
  отклонения» найти не удалось. Наше измерение: −0.53% по std, до −0.46% по p99.
- Поправки конечной высоты: [Bogomolny–Bohigas–Leboeuf–Monastra 2006](https://arxiv.org/pdf/math/0602270)
  дают явную формулу с \(N_{\text{eff}}\approx 0.230158\,L\) и масштабной поправкой
  \(\alpha-1 = 1.4720/L\). На нашей высоте \(L=\ln(T/2\pi)\approx 9.4\):
  \(N_{\text{eff}}\approx 2.16\), \(\alpha-1\approx 0.157\). То есть 15–16%
  сдвиг аргумента — величина того же порядка (даже больше), чем наблюдённый
  дефицит std 5.5%.
- [Odlyzko 1987](https://www.dtc.umn.edu/~odlyzko/doc/arch/zeta.zero.spacing.pdf)
  для первых 10⁵ нулей документирует бо́льшую, чем у GUE, концентрацию расстояний
  вблизи 1 — то есть более узкое распределение. Знак совпадает с нашим дефицитом.
- Что доказано, а что нет: Montgomery 1973 — парная корреляция при RH только для
  тестовых функций с ограниченным носителем Фурье; полная гипотеза не доказана.
  Rudnick–Sarnak — высшие корреляции в той же ограниченной постановке.

**Прямой вывод исследования:** явной опубликованной величины «−5.5% по std и
−2.2% по p95 на высоте 7.5·10⁴» в рецензируемой литературе нет. Порядок и знак
согласуются с BBLM 2006 и наблюдением Одлыжко, но количественный мост между
формулой BBLM и нашими процентами никем не построен. Единственный источник с
готовым числом — непроверенный препринт на Zenodo, и он про статистику
отношения расстояний, а не про std/p95. Поэтому вердикт сита по этому
утверждению остаётся **ВОПРОС**, и это единственный честный статус: не находка,
не подтверждение.

### Что это даёт как теорема-подобное следствие

Из формулы BBLM следует, что поправка входит как масштабирование \(s\to\alpha s\)
с \(\alpha-1 = 1.4720/L\). Масштабирование аргумента умножает и std, и любой
квантиль на \(1/\alpha\) в первом порядке, то есть предсказывает **одинаковый
относительный сдвиг всех статистик**. Наши измерения этому не подчиняются:
std −5.50%, p90 −2.11%, p95 −2.17%, p99 −2.47%, p50 +0.29%. Дефицит std в 2.5
раза больше дефицита квантилей, а медиана вовсе не сдвинута. Значит, чистое
масштабирование аргумента наблюдаемую картину не объясняет — нужен либо член,
меняющий форму распределения (\(\delta p(s)\) у BBLM, а не только \(\alpha\)),
либо причина вне теории конечной высоты. Это проверяемое следствие, и оно уже
зафиксировано в сите как открытый пункт С9: «объясняет p50, p90, но не std, p95, p99».

## 7. Три варианта сотрудничества для следующего лупа

1. **Мост BBLM → проценты.** Численно проинтегрировать формулу
   Bogomolny–Bohigas–Leboeuf–Monastra 2006 для \(p(s)=p_0(s)+\delta p(s)\) на
   \(L\approx 9.4\) и получить предсказанные std и p95 — то есть построить тот
   мост, которого в литературе нет. Тогда вердикт по главному утверждению
   перестанет быть ВОПРОСОМ: либо конечная высота объясняет дефицит, либо нет,
   и это будет машинный вывод. Это и научный результат, и закрытие открытого С9.
2. **Калибровка сит на корпусе.** Прогнать каскад по 30–50 утверждениям из самых
   насыщенных файлов (`sacred-formulas.md`, `MASTER_SACRED_CATALOG.md`,
   `transcendental-numbers.md`) и измерить для каждого сита частоту ложных
   срабатываний, как это сделано у statcheck. Даёт покрытие с 0.2% до заметного
   и цифру доверия к самому инструменту.
3. **Сито совместной реализуемости + метаморфные отношения.** Перенять GRIM/SPRITE
   (могут ли заявленные числа вообще получиться из одной выборки данного объёма) и
   декларативные метаморфные отношения вместо частных `estimators`. Это расширяет
   сито на утверждения, у которых внешнего эталона нет вовсе — а таких в корпусе
   большинство.

Замечания по честности соблюдены: триаж не выдан за аудит, ВОПРОС и ПУСТО не
поданы как находки, слов «первый/единственный/лучший» нет, каталог форматов не
затрагивался, кремний не упоминался.
